Install on your device

Android: Open the secure HTTPS portal in Chrome. Tap the browser menu, then Install app or Add to Home screen.

iPhone/iPad: Open the secure HTTPS portal in Safari. Tap Share → Add to Home Screen → Add.

Windows: In Edge or Chrome, use the Install app option in the address bar or browser menu.

For the IT team

Mobile PWA installation requires a valid, trusted HTTPS origin. An internal HTTP IP such as http://192.168.x.x:8000 will not qualify.

Ensure /manifest.webmanifest, /service-worker.js, the icon URLs and all required static files load over HTTPS. A trusted internal certificate must also be trusted by employee devices.

Authentication and media access should be tested in standalone mode. This app does not cache confidential employee data for offline access.
